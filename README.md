# GLOBCOAST
**GLOBCOAST** is a global shoreline evolution model designed to simulate sandy shoreline changes under climatic and anthropogenic forcing using simplified morphodynamic processes and globally available datasets.

## Key features
- Global shoreline and waterline evolution model based on simplified morphodynamics  
- Integrates sea-level variability, longshore sediment transport, fluvial inputs, and wave-driven beach slope changes   
- Applicable in data-scarce regions and scalable from seasonal to multi-annual timescales  
- Designed for coastal risk assessment and large-scale comparative analyses  

## Installation
No installation is required.

To run GLOBCOAST, simply download or clone the repository and use the provided Jupyter notebooks.

git clone https://github.com/AmelieArias/GLOBCOAST.git

cd GLOBCOAST

## Reproducing published results
This repository contains scripts and configuration files used to reproduce results presented in: 
- Arias et al., 2026, Regional Studies in Marine Science, https://doi.org/10.1016/j.rsma.2025.104668
